# Task dispatch

- Task / milestone ID
- Outcome and requirement IDs
- Assigned actor / model / harness / reasoning / session or run ID
- Role skill path and revision
- Input artifact versions and digests
- Dependencies and provisional assumptions
- Allowed write scope and shared-resource owner
- Expected output artifact IDs, versions, and paths
- Acceptance criteria and relevant self-check commands or methods
- Budget, quota, time constraint, and retry boundary
- Required independent reviewer and next recipient
- Existing authorization and reserved decisions
- Acknowledgement, checkpoints, current state, and final receipt
